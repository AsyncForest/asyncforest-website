Design law

Break the default aesthetic

This brand is monochrome, sans, and structural by decision — not by default. These rules keep it from collapsing into generic "AI-slop". Audit every screen against them before shipping.

Never (unless asked)

  • ✕Teal / a second accent. Ink is the action colour; a single deep blue is the one rare highlight.
  • ✕Animated status dots, pulsing orbs, "live" badges. Status is static text + glyph.
  • ✕Container depth > 2. No card-on-card — separate with a hairline or tonal shift.
  • ✕Serif headline + sans body. Inter / Roboto / Arial / system-ui as the primary face.
  • ✕Three-column feature grid in the hero or section 2. The "Get Started / Learn More" duo.
  • ✕Decorative coloured left-rules. The rule is reserved for severity only (Callout).
  • ✕Mixing icon families. Purple-pink gradients. Glass / frosted hero stacks.

Prefer

  • →One bold direction (monochrome + Hanken Grotesk) over hedged "modern minimal".
  • →Tactile block elevation (solid offset shadow, presses in) over soft drop shadows.
  • →Editorial rhythm — max-width prose, vertical breathing — over uniform grids.
  • →Content-first heroes (type, a report, a table) over decorative ones.
  • →One icon family: Lucide, stroke 1.75 — or type-only. Never decorative icons.
  • →Verb-first, product-specific copy ("Start a conversation", not "Get started").
  • →Motion that communicates state or hierarchy; otherwise none. Respect reduced-motion.

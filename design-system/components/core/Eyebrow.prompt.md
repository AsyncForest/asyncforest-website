**Eyebrow** — the mono, uppercase, letter-spaced tag that opens a section or heading. This is a core brand signature; use it above most headlines and to label metadata.

```jsx
<Eyebrow>Independent technical assurance</Eyebrow>
<Eyebrow tick>Emerging service</Eyebrow>
```

Keep the text short (2–4 words). `tick` adds a small ink square. Pairs directly above a heading.
